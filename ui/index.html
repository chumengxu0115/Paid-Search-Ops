    WHO DID WHAT

    Python calculated, Claude Code authored, humans decide

    • Python (src/compute_metrics.py): parsed the two CSVs, recomputed every ratio with decimal arithmetic, reconciled totals and wrote the checks shown here.
    • Claude Code: authored the saved interpretation (diagnosis v1, then independent review v2 → v2.1 → v2.2). Every number in that text is filled from the step 1 output by a build script that fails on an unknown reference.
    • This dashboard: renders the canonical JSON and stores your notes in this browser. There is no live model call, no runtime log of an AI run, and no ad-account connection.

    REANALYSIS HANDOFF

    How your feedback reaches the next analysis

    1. Add notes, answers and decisions in Search Terms. They autosave to this browser only.
    2. Click Export feedback for Claude Code to download operator_feedback.json. It carries the analysis identity so it cannot be applied to a different dataset.
    3. Save the file into the project (e.g. operator/operator_feedback.json) and ask Claude Code to produce a new review version that consumes it. The canonical baseline stays unchanged; a new version is built alongside it.
    4. Import the same file here later to restore notes on another browser.

    There is no “reanalyze” button because no model runs inside this page.
